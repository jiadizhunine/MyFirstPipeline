# MyFirstPipeline

Group Three, BPSM ICA1.

On the course server, decrypt and run:

```bash
ccrypt -c Group_Three.MyFirstPipeline.tar.gz.cpt | tar -xz
cd MyFirstPipeline
. ./run.sh
```

Enter the decryption key when prompted. Inputs are in
`/localdisk/data/BPSM/MyFirstPipeline`.

The six folders follow the assignment steps. Each script can also be run
from its own folder with `. ./script.sh`. Results stay in the corresponding
folder. The archive includes the code and `all_the_things_I_did` Git log.
